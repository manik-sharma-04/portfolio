# Instructions for Images

Place your image files in this folder (`assets/images/`).
Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`

### Required Image Filenames:
1. `profile.jpg` (or `.png`): Your professional photo for the About/Hero section.
2. `project-car-price.jpg` (or `.png`): Thumbnail/screenshot for the Car Price Prediction project.
3. `project-calories.jpg` (or `.png`): Thumbnail/screenshot for the Calories Burnt Prediction project.
4. `project-hr-analytics.jpg` (or `.png`): Thumbnail/screenshot for the HR Analytics project.
5. `certificate-ai900.jpg` (or `.png`): Microsoft Azure AI Fundamentals certificate image.
6. `certificate-az900.jpg` (or `.png`): Microsoft Azure Fundamentals certificate image.

> Note: If any image is a `.png` instead of `.jpg`, simply open `index.html` and change `.jpg` to `.png` in the corresponding `<img>` tag.
